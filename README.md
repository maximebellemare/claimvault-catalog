# ClaimVault public settlement catalog

This repository serves **public, administrator-sourced settlement metadata only**. It contains no user profiles, receipts, personal details, account credentials, or iOS application source.

## Live catalog
- [cases-reviewed.json](./cases-reviewed.json) — independently curated records with official settlement links, deadlines and preliminary screening questions.

**Important:** Case listing does not establish legal eligibility, guarantee a payment or file a claim. Claimants should always confirm conditions and deadlines with the court-authorized settlement administrator. Filing directly with the administrator is free. Current cases are automatically filtered for expired deadlines in the ClaimVault application.

## Publication policy
- News/RSS discoveries from the private ClaimVault project are never copied directly into this catalog.
- Add records only after a human checks the official notice, claim form, class definition, benefit terms, deadlines, exclusions and evidence requirements.
- Do not publish incomplete records or personal data.
- Do not modify any existing case to extend its deadline without checking the administrator notice.
- No payment, user account or receipt data is handled here.

The private application source remains in a separate private repository.
